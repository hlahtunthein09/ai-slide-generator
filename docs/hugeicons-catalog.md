# Hugeicons Shortlist for AI Presentation Generator

This catalog contains 300 local Hugeicons candidates selected for recurring
student-presentation topics. It is a review list only: no icon has been copied
into `frontend/` or connected to the renderer yet.

The later renderer mapping should select a single semantic icon per slide. It
must not treat this as a request to show multiple icons or to decorate every
slide.
