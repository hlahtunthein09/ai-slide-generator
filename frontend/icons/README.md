## Usage

Reference an icon as a local file from the slide template:

```html
<img src="icons/brain.svg" alt="Brain icon">
```

Or inline the SVG directly into the slide HTML for easy CSS coloring:

```css
.slide-icon {
  width: 96px;
  height: 96px;
  color: var(--accent);
}
```
